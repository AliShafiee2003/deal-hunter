# شکارچی تخفیف‌های ویژه (اسنپ‌شاپ + دیجی‌کالا) ⚡
### Deal Hunter & Fast-Buy Monitor for SnappShop & Digikala

یک پلتفرم پایش سریع، خودکار و چندرشته‌ای (Concurrent Crawler) نوشته شده به زبان Go برای رصد تخفیف‌های بلک‌فرایدی و حراج‌های ویژه اسنپ‌شاپ و دیجی‌کالا با قابلیت خرید ۱-کلیکه.

---

## 🚀 ویژگی‌ها (Features)

- **پایش همزمان دو فروشگاه بزرگ ایران:** اسنپ‌شاپ (SnappShop) و دیجی‌کالا (Digikala)
- **پوشش ۲۷ دسته‌بندی جامع:**
  - هارد اکسترنال، SSD، لپ‌تاپ و کامپیوتر
  - گوشی موبایل، تبلت، هدفون، اسپیکر، ساعت هوشمند، پاوربانک
  - لوازم خانگی، تلویزیون، یخچال، ماشین لباسشویی، جاروبرقی
  - قهوه‌ساز و تمپر، زیبایی و آرایشی، مکمل و سلامت، عینک طبی
  - مد و پوشاک، کفش، طلا و نقره، ابزارآلات و خودرو، سوپرمارکت، کتاب و اسباب‌بازی
- **پایش عمیق چندصفحه‌ای:** استخراج تا ۵ صفحه در هر دسته با مرتب‌سازی بیشترین درصد تخفیف
- **خرید ۱-کلیکه (Fast Buy Userscript):** اسکریپت Tampermonkey برای افزودن مستقیم به سبد خرید و هدایت به صفحه ثبت سفارش (`/checkout/shipping`)
- **داشبورد وب بلادرنگ (Web Dashboard):**
  - فیلتر بر اساس فروشگاه (همه، فقط اسنپ‌شاپ، فقط دیجی‌کالا)
  - فیلتر بر اساس حداقل درصد تخفیف (۷۰٪، ۸۰٪، ۵۰٪، ۳۰٪)
  - فیلتر سقف قیمت (تومان)
  - مرتب‌سازی ۴ حالته (بیشترین تخفیف، ارزان‌ترین، گران‌ترین، جدیدترین)
  - جستجوی آنی در عناوین محصولات
  - ذخیره‌سازی و پایداری داده‌ها روی دیسک (Persistent Cache)
- **کنترل نرخ درخواست (Anti-Rate-Limit):** سیستم Throttling هوشمند برای جلوگیری از خطای `429 Too Many Requests`

## 🛠️ نصب و راه‌اندازی (Getting Started)

### پیش‌نیازها
- نصب [Go](https://go.dev/) (نسخه 1.20 به بالا)

### اجرای سرور پایش:
```bash
# بیلد و اجرای سرور
go build -o snapp_server.exe server.go
./snapp_server.exe -port 8080 -interval 60 -no-browser
```

سپس در مرورگر خود به آدرس زیر بروید:
```
http://localhost:8080
```

### فعال‌سازی خرید ۱-کلیکه:
1. افزونه [Tampermonkey](https://www.tampermonkey.net/) را در مرورگر خود نصب کنید.
2. اسکریپت `snapp_fast_buy.user.js` را در Tampermonkey نصب کنید (یا از طریق دکمه موجود در بالای داشبورد).
